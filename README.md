# هاكر تيوب عربي (HackerTube AR)

فهرس فيديوهات برمجية عربية من قنوات مختارة، بتصميم بسيط يشبه يوتيوب وفلترة أدق
من مجرد قائمة تشغيل: الموضوع، المستوى، النوع، المدة، السنة، القناة، وبحث عربي
يطبّع الهمزات والتاء المربوطة والتشكيل.

مستوحى من [hackertube.org](https://hackertube.org) لكنه مختلف: الأصل يعتمد توصيات
Hacker News بالإنجليزية، وهذا المشروع يركّز على محتوى القنوات البرمجية العربية
(الزيرو، يحيى تك، ذا نيو بغداد، كودزيلا، وغيرها) ويعطيك فلاتر للوصول إليه.

## التشغيل

```bash
# من جذر المشروع
python -m http.server 8080 -d public
# ثم افتح http://localhost:8080
```

لا يحتاج خادم تطبيق ولا قاعدة بيانات: الموقع ملفات ثابتة + JSON.

## بناء البيانات

```bash
pip install -r requirements.txt
python -m pipeline.fetch     # يجلب أحدث 300 فيديو لكل قناة إلى data/raw/
python -m pipeline.build     # ينتج public/data/videos.json و meta.json
pytest                       # الاختبارات
```

## البنية

```
pipeline/        الجلب والتصنيف والبناء (Python + yt-dlp)
public/          الموقع الثابت (HTML/CSS/JS بدون أطر عمل)
public/data/     الفهرس المولّد
tests/           اختبارات التطبيع والتصنيف والبيانات
```

## القيود المعروفة

- التصنيف يعتمد على عنوان الفيديو فقط، بلا وصف ولا نموذج لغوي.
- نجلب أحدث 300 فيديو لكل قناة، فالقنوات القديمة الكبيرة غير مغطاة بالكامل.
- تاريخ النشر تقريبي (yt-dlp approximate_date).
- لا توصيات شخصية ولا حسابات؛ الحفظ والإعجاب محليان في المتصفح.
- لا نستضيف الفيديو؛ التشغيل عبر youtube-nocookie، والحقوق لأصحاب القنوات.

## الترخيص

كود المشروع MIT. بيانات الفيديوهات (العناوين والمعرّفات والمشاهدات) ملك أصحابها
على يوتيوب، وتستخدم هنا للفهرسة فقط.
